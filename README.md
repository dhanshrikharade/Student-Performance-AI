✨ Features

📊 Student Performance Analysis — Analyze student marks and academic results.

🏆 Student Ranking — Calculate rankings based on total marks.

📈 Interactive Visualizations — Explore performance through charts and graphs.

📋 Academic Statistics — View averages and overall performance summaries.

🖥️ Interactive Web Interface — Access analysis through a Streamlit dashboard.

📂 Dataset Support — Includes sample Mathematics and Portuguese student datasets.

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/dhanshrikharade/Student-Performance-AI.git

2. Open the project directory

cd Student-Performance-AI

3. Install dependencies

python -m pip install streamlit pandas plotly

4. Run the application

python -m streamlit run app.py

The application will open in your browser, usually at http://localhost:8501.

🎯 Project Objective

The objective of this project is to simplify student academic performance analysis by presenting marks, rankings, and performance statistics in an interactive dashboard.
